# baggyHood landing page

A responsive React + Tailwind CSS landing page concept for the baggyHood oversized denim launch.

## Run locally

```bash
npm install
npm run dev
```

Vite will print a local URL, usually `http://localhost:5173`.

## Before launch

- Replace the Unsplash image URLs with your own original product and campaign photography.
- Verify the actual fabric weight and final product measurements before claiming them on the site.
- The waitlist form currently validates the field and shows a demo success state, but it does **not** save or send leads. Connect Formspree, Supabase, Firebase, your own API, or a WhatsApp flow before publishing.
- Add your actual Instagram / WhatsApp links and privacy policy.
- Add an explicit privacy consent notice if you collect phone numbers.
- Review all size chart values: these are illustrative placeholders, not verified product specifications.
